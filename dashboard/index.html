How It Works

Three steps. Zero workflow files.

1

Push a tag

Tag a commit with v1.3.0 and push it. Release Pilot listens for the webhook.

2

We read your commits

Every commit since the previous tag is parsed, classified, and matched to its PR.

3

Draft release appears

A grouped, sectioned, contributor-credited draft lands in the Releases tab, ready to publish.

Live Demo

Paste conventional commit messages, one per line. We'll generate the release notes locally in your browser.
